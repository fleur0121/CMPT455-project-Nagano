# EDA and Preprocessing submission

The ZIP contains one executed notebook, the report, its two Python dependencies, and the package list. Extract it before running the notebook. Keep the directory structure intact.

From the extracted directory, install dependencies with `python -m pip install -r requirements.txt`, then open `EDA_Preprocessing.ipynb` in Jupyter, Colab, or Kaggle and run all cells in order. Internet access is required on the first run to download the public UCI Census-Income files; generated data is not included in the ZIP.

The notebook checks data overview, missing values, exact duplicates, distributions, correlations, preprocessing choices, mutual-information ranking, and PCA. Its figures are generated by code. The held-out test split is not scored.
